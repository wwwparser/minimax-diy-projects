Многоярусная полка для цветов на подоконник

Ступенчатая полка-горка для рассады и суккулентов на подоконник.

сложность 1/5~2 ч700×145, три яруса
1339 ₽смета с оснасткой
  1. Напилить полки
  2. Сделать боковины-ступени
  3. Прикрутить полки
  4. Покрыть лаком

Как сделать подробно

  1. Отпилить 3 полки 700 мм из доски 20×145.
  2. Из бруска 20×45 сделать 2 боковины-ступеньки высотой 100/200/300 мм.
  3. Прикрутить полки к боковинам саморезами 41 мм.
  4. Покрыть яхтным лаком — не боится воды при поливе.
