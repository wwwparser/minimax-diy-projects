Угловая треугольная полка

Две треугольные полочки из квадрата фанеры, распиленного по диагонали, на опорных планках в углу.

сложность 1/5~1.5 чкатеты 505 мм, 2 яруса
1567 ₽смета с оснасткой
  1. Распилить фанеру по диагонали
  2. Прикрутить планки к стенам
  3. Уложить полки
  4. Покрыть кромки лаком

Как сделать подробно

  1. Распилить фанеру 505×505 по диагонали — две полки.
  2. Из бруска 20×30 нарезать опорные планки по двум стенам.
  3. Прикрутить планки к стенам на дюбели, проверив уровень.
  4. Положить полки и закрепить саморезами 32 мм сверху.
  5. Кромку фанеры покрыть лаком.
