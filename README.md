# Проекты под шуруповёрт Интерскол ДА-10/12В

Подбор простых недорогих проектов из дерева и металла под аккумуляторную дрель-шуруповёрт
12 В / 36 Н·м, со сметой по каталогу «Петровича» (≤ 3000 ₽ на проект, включая оснастку и
расходники) и плакатами для 10 лучших.

## Результат

| Файл | Что внутри |
|---|---|
| `out/projects.xlsx` | лист «Проекты» (57 шт., сумма, сложность, время, источник) + лист «Сметы» (каждая позиция: артикул, цена, кол-во, ссылка) |
| `out/PROJECTS.md` | те же 57 проектов с шагами и таблицами покупок, топ-10 сверху |
| `out/estimates.json` | машиночитаемые сметы |
| `out/posters/prompts.json` | промпты плакатов для топ-10 |
| `out/posters/*.png` | плакаты из ChatGPT |

Цены — розница Петровича, Москва, снимок каталога 16.09.2026 (`idea-parser-petrovich`).

## Правила отбора

- Только шуруповёрт + ручной инструмент: ножовка, стусло, ножовка по металлу. Без сварки,
  болгарки, лобзика, циркулярки (такие проекты из выдачи отброшены или переделаны на болты/саморезы).
- 12 В / 36 Н·м: отверстия в металле до 8 мм на 1-й скорости, в дереве перьевые до 25 мм и
  коронки до 54 мм; длинные саморезы — с засверловкой.
- В каждой смете — всё, что нужно купить, если дома только шуруповёрт: биты, свёрла, пила,
  стусло, рулетка, шкурка, отделка. Повторная покупка оснастки для второго проекта не нужна —
  реальные траты на серию проектов меньше суммы смет.

## Варианты реализации (из задачи IDEA.md)

1. **MVP (сделано):** выдача → извлечение → ручная адаптация и BOM по артикулам → Excel/Markdown → плакаты в ChatGPT.
2. **Автоподбор BOM:** LLM переводит материалы статьи в поисковые запросы, FTS находит кандидатов,
   LLM выбирает; человек проверяет. Масштабируется на сотни проектов, но ошибки в размерах/упаковках.
3. **Веб-каталог:** статический сайт с фильтрами (материал, бюджет, сложность) и кнопкой «корзина Петровича».

Риски: цены в снимке устаревают (перезапуск парсера), размеры упаковок в каталоге путаются
(«упак» vs «шт»), генератор картинок искажает русский текст на плакате, бесплатный пул OpenRouter
очень медленный (1 страница ≈ 10 мин — поэтому извлечение сделали агенты), Browser Bridge общий с
другими проектами (`idea-realyoga-zapis-video` закрепляет свою вкладку — не запускать плакаты во время записи).

Трудозатраты MVP: ~1 день. Вариант 2: +1–2 дня. Вариант 3: +2–3 дня.
