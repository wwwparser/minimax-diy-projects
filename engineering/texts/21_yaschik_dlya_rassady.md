# 21. Ящик для рассады
project_id: 21_yaschik_dlya_rassady
Материал: дерево; сложность 1/5; ~1.5 ч
Размер (из шапки текста): 600×300×100 мм

Описание: Невысокий ящик на подоконник под стаканчики рассады, с поддоном из плёнки.

Шаги из текста:
1. Нарезать доску 20×95: 2 стенки 600, 2 торца 260 мм, дно из 3 досок 600 мм.
2. Собрать на саморезы 32 мм, засверливая 3 мм.
3. Пропитать антисептиком, высушить.
