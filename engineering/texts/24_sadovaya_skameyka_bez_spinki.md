# 24. Садовая скамейка без спинки
project_id: 24_sadovaya_skameyka_bez_spinki
Материал: дерево; сложность 2/5; ~4 ч
Размер (из шапки текста): 1000×300, высота 430 мм

Описание: Короткая крепкая лавка из доски 45×95 на ножках из бруска 50×50, на конструкционных саморезах.

Шаги из текста:
1. Нарезать доску 45×95×3000 на 3 части по 1000 мм — сиденье.
2. 4 ножки по 410 мм из бруска 50×50, 2 царги 300 мм из доски 20×95.
3. Собрать 2 П-образные опоры на конструкционные саморезы.
4. Прикрутить доски сиденья с зазором 8 мм.
5. Пропитать антисептиком.
