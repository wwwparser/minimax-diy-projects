# 13. Ключница «домик»
project_id: 13_klyuchnica_domik
Материал: дерево; сложность 1/5; ~1.5 ч
Размер (из шапки текста): 300×250 мм

Описание: Настенная ключница в форме домика с крючками и полочкой для писем.

Шаги из текста:
1. Отпилить 3 куска доски 300 мм, два верхних угла спилить под 45° — получится домик.
2. Склеить куски между собой через поперечную планку сзади.
3. Снизу прикрутить полочку из обрезка.
4. Вкрутить 5 крючков, покрыть морилкой, повесить на дюбели.
