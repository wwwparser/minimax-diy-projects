# 15. Сервировочный поднос с ручками
project_id: 15_servirovochnyy_podnos_s_ruchkami
Материал: дерево; сложность 1/5; ~2 ч
Размер (из шапки текста): 450×300 мм

Описание: Поднос для завтрака: дно из досок, бортики из раскладки, деревянные ручки-скобы, пропитка маслом.

Шаги из текста:
1. Нарезать 3 доски 20×95 по 450 мм, соединить снизу двумя планками.
2. Бортики из раскладки на клей и мелкие саморезы 25 мм, углы в стусле 45°.
3. Прикрутить ручки-скобы к торцам.
4. Отшлифовать и пропитать льняным маслом.
