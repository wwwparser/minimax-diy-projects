# 4. Кормушка-домик с двускатной крышей
project_id: 04_kormushka_domik_s_dvuskatnoy_kryshey
Материал: дерево; сложность 2/5; ~2.5 ч
Размер (из шапки текста): дно 200×250, высота 250 мм

Описание: Кормушка под крышей: корм не мокнет. Крыша из двух досок встык, стойки из бруска.

Шаги из текста:
1. Дно 250 мм из двух кусков доски 20×95, по краям бортики из бруска 20×30.
2. Четыре стойки 150 мм из бруска прикрутить к углам дна.
3. Фронтоны: два куска доски, спиленные в стусле под 45° «домиком», прикрутить к стойкам.
4. Крыша — 4 куска доски 300 мм на саморезы 32 мм.
5. Шуруп-кольцо в конёк, повесить на шнур.
