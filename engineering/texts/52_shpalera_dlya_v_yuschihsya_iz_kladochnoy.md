# 52. Шпалера для вьющихся из кладочной сетки
project_id: 52_shpalera_dlya_v_yuschihsya_iz_kladochnoy
Материал: дерево+металл; сложность 1/5; ~2 ч
Размер (из шапки текста): 2000×500 мм

Описание: Опора для огурцов, клематиса или девичьего винограда: оцинкованная сетка на рамке из бруса.

Шаги из текста:
1. Нарезать брусок 40×40: 2 стойки 2000 мм (заглубить 400) и 2 поперечины 500 мм.
2. Собрать раму на саморезы 75 мм.
3. Прикрутить сетку саморезами 25 мм с кузовными шайбами.
4. Пропитать дерево антисептиком, вкопать.
