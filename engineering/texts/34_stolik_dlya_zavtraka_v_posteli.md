# 34. Столик для завтрака в постели
project_id: 34_stolik_dlya_zavtraka_v_posteli
Материал: дерево; сложность 2/5; ~2.5 ч
Размер (из шапки текста): 800×300, ножки 250 мм, складные

Описание: Столик из мебельного щита с откидными ножками на петлях и ручками по бокам.

Шаги из текста:
1. Щит ЛДСП 800×300 — столешница.
2. Из бруска 20×45 сделать две П-образные ножки высотой 250 мм.
3. Прикрутить ножки к столешнице на карточные петли — складываются внутрь.
4. По торцам — ручки-скобы.
5. Кромки бруска отшлифовать.
