# 18. Многоярусная полка для цветов на подоконник
project_id: 18_mnogoyarusnaya_polka_dlya_cvetov_na_podo
Материал: дерево; сложность 1/5; ~2 ч
Размер (из шапки текста): 700×145, три яруса

Описание: Ступенчатая полка-горка для рассады и суккулентов на подоконник.

Шаги из текста:
1. Отпилить 3 полки 700 мм из доски 20×145.
2. Из бруска 20×45 сделать 2 боковины-ступеньки высотой 100/200/300 мм.
3. Прикрутить полки к боковинам саморезами 41 мм.
4. Покрыть яхтным лаком — не боится воды при поливе.
