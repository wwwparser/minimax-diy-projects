# 9. Этажерка над унитазом
project_id: 09_etazherka_nad_unitazom
Материал: дерево; сложность 2/5; ~3 ч
Размер (из шапки текста): 600×170, высота 1000 мм

Описание: Узкая лесенка-стеллаж на три полки в санузел. Стойки из бруска 20×45, полки из доски 20×120.

Шаги из текста:
1. Нарезать 4 стойки по 1000 мм из бруска 20×45 (из 2 брусков), 3 полки по 600 из доски 20×120.
2. Под полки прикрутить опорные планки из оставшегося бруска.
3. Собрать на саморезы 51 мм, проверить угольником каждой полки.
4. Покрыть яхтным лаком — не боится влаги.
5. Верх прикрутить к стене через уголок, чтобы не опрокинулась.
