# 16. Складная подставка-лесенка для цветов
project_id: 16_skladnaya_podstavka_lesenka_dlya_cvetov
Материал: дерево; сложность 2/5; ~3 ч
Размер (из шапки текста): А-рама 900 мм, 3 полки

Описание: А-образная этажерка на петлях: раскладывается на балконе, складывается на зиму.

Шаги из текста:
1. Из брусков 20×45 нарезать 4 ноги по 900 мм и перекладины.
2. Собрать две лестницы-рамы на саморезы 41 мм.
3. Верх рам соединить двумя петлями.
4. Полки из доски 20×120 положить на перекладины обеих рам.
5. Покрыть антисептиком.
