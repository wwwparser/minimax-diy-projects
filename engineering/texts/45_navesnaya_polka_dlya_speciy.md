# 45. Навесная полка для специй
project_id: 45_navesnaya_polka_dlya_speciy
Материал: дерево; сложность 1/5; ~1.5 ч
Размер (из шапки текста): 500×95 мм, 2 яруса

Описание: Две узкие полочки с бортиками из раскладки — баночки не падают.

Шаги из текста:
1. Нарезать доску 20×95: 2 полки 500, 2 боковины 350 мм.
2. Прикрутить полки к боковинам саморезами 32 мм.
3. Спереди приклеить бортики из раскладки.
4. Покрыть лаком, повесить на дюбели.
