# 32. Угловая треугольная полка
project_id: 32_uglovaya_treugol_naya_polka
Материал: дерево; сложность 1/5; ~1.5 ч
Размер (из шапки текста): катеты 505 мм, 2 яруса

Описание: Две треугольные полочки из квадрата фанеры, распиленного по диагонали, на опорных планках в углу.

Шаги из текста:
1. Распилить фанеру 505×505 по диагонали — две полки.
2. Из бруска 20×30 нарезать опорные планки по двум стенам.
3. Прикрутить планки к стенам на дюбели, проверив уровень.
4. Положить полки и закрепить саморезами 32 мм сверху.
5. Кромку фанеры покрыть лаком.
