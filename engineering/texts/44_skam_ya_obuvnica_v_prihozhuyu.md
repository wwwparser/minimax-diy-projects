# 44. Скамья-обувница в прихожую
project_id: 44_skam_ya_obuvnica_v_prihozhuyu
Материал: дерево; сложность 2/5; ~4 ч
Размер (из шапки текста): 900×290×450 мм

Описание: Сиденье сверху и полка для обуви снизу — надевать ботинки сидя.

Шаги из текста:
1. Нарезать 4 ноги 450 мм из бруска 40×40.
2. Сиденье — 2 доски 20×145 по 900, полка — 2 доски по 900.
3. Собрать боковины с перекладинами, прикрутить доски саморезами 51 мм.
4. Лак.
