# 47. Вешалка-штанга лофт: стальная труба на деревянных держателях
project_id: 47_veshalka_shtanga_loft_stal_naya_truba_na
Материал: дерево+металл; сложность 2/5; ~3 ч
Размер (из шапки текста): длина 1000 мм

Описание: Открытая вешалка для одежды: водогазопроводная труба ДУ15 в держателях из доски, крашенная в чёрный.

Шаги из текста:
1. Отпилить трубу ножовкой по металлу на 1000 мм, зачистить торцы шкуркой.
2. Из доски 20×145 склеить 2 держателя 300×145, в каждом перьевым сверлом 22 мм сделать гнездо.
3. Покрасить трубу грунт-эмалью.
4. Прикрутить держатели к стене на дюбели, вставить трубу.
