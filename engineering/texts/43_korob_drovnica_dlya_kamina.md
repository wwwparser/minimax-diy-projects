# 43. Короб-дровница для камина
project_id: 43_korob_drovnica_dlya_kamina
Материал: дерево; сложность 2/5; ~3 ч
Размер (из шапки текста): 600×350×350 мм

Описание: Короб для поленьев у печки или камина с ручками по бокам.

Шаги из текста:
1. Нарезать доску 20×145 на рейки стенок 600 и 310 мм, угловые стойки из бруска 40×40.
2. Собрать стенки с зазором 10 мм — дрова проветриваются.
3. Дно из досок.
4. Ручки-скобы по торцам.
5. Морилка.
