# Заметки: 27. Ящик для инструментов с ручкой

- Шапка текста заявляет габарит 500×200×250 мм. Глубина короба по модели 145 мм (доска 20×145, борта
  и дно взяты как есть), а не 200 — конфликт оставлен в claims (`spec.conflict_overall`), не подогнан.
  Высота торцов «домиком» 250 мм совпадает с моделью, но полная высота сборки с ручкой поверху — 290 мм.
- Торцы «домиком» смоделированы пятиугольником (прямоугольная нижняя часть 190 мм + треугольный скат до
  пика на высоте 250 мм), ширина торца уменьшена до 105 мм (роспуск из доски 145 мм, чтобы торец вставал
  между бортами по образцу короба-шаблона из SKILL.md) — числом в тексте не задана, принята симметрично.
- Ручка 540 мм длиннее короба (500 мм) на 40 мм — выступает по 20 мм за каждый торец; крепится сверху к
  пиковой кромке торцов, для нормального шва (движок иначе даёт `fastener.seam_too_short`) ширина контакта
  по Y расширена до 45 мм (вся ширина бруска ручки уложена вдоль борта, а не поперёк).
- Текст даёт единую длину самореза 32 мм для сборки короба; для угловых соединений и дна заход получается
  12 мм < 4d(14 мм) — движок закономерно показывает `fastener.penetration_low`. Это ошибка проекта (текст
  сам даёт слишком короткий саморез для сборки короба из доски 20 мм), оставлена как есть.
- Для ручки длину самореза текст не называет — оставлена на подбор движку (не форсировалась в 32 мм).

Итог validate: error, 7 ошибок (6×`fastener.penetration_low` + 1×`spec.conflict_overall`, все проектные),
14 предупреждений (в основном edge_distance + ambiguity).
