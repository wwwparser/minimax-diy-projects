# 53. Компостер-цилиндр из кладочной сетки — заметки

- Деталь mesh_cyl (лист сетки 1×2 м) не размещена геометрически (нет `at`) — по правилу навыка
  для кладочной сетки, свёрнутой в цилиндр, это допустимо; движок даёт только warning
  `part.not_placed`, не error.
- Крепёж нахлёста (4 болта М6х30 + гайки + кузовные шайбы) соединяет сетку саму с собой
  (внахлёст), а не две разные детали — смоделировать как `joint` нельзя (part_a/part_b
  требуют двух деталей). Заведено как `hardware` (cyl_bolts, type: other) — только чтобы
  попасть в смету/BOM.
- sku материала `1156584` (сетка) намеренно оставлен как в ручной смете, хотя в
  `catalog_petrovich.yaml` его нет. Ожидал явную ошибку `bom.not_in_catalog`, но движок для
  материалов (в отличие от крепежа/фурнитуры) при отсутствии sku в каталоге молча
  использует собственную длину заготовки с ценой 0 — поэтому итоговая смета validate
  (503 ₽) учитывает только болты (sku 101038, есть в каталоге), сетка в неё фактически не
  вошла. Это стоит учесть при финальной оценке бюджета проекта — сумма занижена.
- Колышки из обрезков (шаг 3) — расходник без артикула, в модели не смоделированы.
- Диаметр цилиндра в модель не заведён как claim (claims.overall сверяет прямоугольный
  bbox X/Y/Z, а не диаметр окружности — так закладывать величину было бы некорректно).
  Проверил вручную: лист 1×2 м, высота цилиндра = 1 м (сторона листа, совпадает с 1000 мм
  из шапки), окружность = 2 м (вторая сторона листа) → расчётный диаметр 2000/π ≈ 636.6 мм,
  почти точно совпадает с заявленными 640 мм (~0.5% расхождения) — физика проекта
  согласована, конфликта нет.
- validate: warning, ошибок 0, предупреждений 5 (part.not_placed + 4×spec.ambiguity).
