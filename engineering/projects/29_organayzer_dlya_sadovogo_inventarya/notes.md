# Заметки: 29. Органайзер для садового инвентаря

- Доска 20×145×1000 (габарит из шапки 1000×145 совпал с моделью без конфликтов).
- Текст просит засверлить перьевым 12мм «под углом вверх» — движок проверяет только позицию отверстия
  на грани детали, наклон сверления геометрически не моделируется (инженерно это не влияет на проверку
  крепежа/раскроя). Отмечено в ambiguities.
- Шканты 12×50 мм (колышки для навески инструмента) — это не силовая деталь каркаса, а вставная
  фурнитура; смоделированы как hardware (mounts на доску), а не как parts с жёсткой геометрией. В каталоге
  Петровича деревянных шкантов как товара нет (только анкерные wall_dowel) — движок закономерно даёт
  `bom.not_in_catalog`/`bom.unpriced` для артикула 640685. Это ожидаемая ошибка проекта, не прятал.
- Количество дюбелей для навески на стену текстом не названо явно — взял 4 шт как разумное для доски
  1000 мм.

Итог validate: warning, 0 ошибок, 5 предупреждений (все — bom.not_in_catalog/unpriced по шкантам и
ambiguity-заметки, ни одной ошибки разметки).
