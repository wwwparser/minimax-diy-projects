# Заметки: 23. Когтеточка-столбик

- Шапка текста: высота 600 мм. Полная высота сборки (столбик 600 мм + фанера основания 12 мм под ним) =
  612 мм — 12 мм разницы; похоже, в шапке названа именно длина заготовки столбика, а не итоговая высота.
  Конфликт зафиксирован в claims (kind overall), движок закономерно даёт `spec.conflict_overall` — не
  подгонял.
- Два самореза 90 мм через фанеру (T=12 мм) в торец бруска 50×50 — движок предупреждает про малый шаг
  между ними (`fastener.spacing_small`, предупреждение, не ошибка): при столбике 50×50 два самореза с
  запасом от края расположены теснее рекомендуемого 5d — это ожидаемо для такого небольшого сечения,
  текст сам просит именно 2 самореза без уточнения раскладки.
- Джутовый канат-обмотка (15 пог. м, d6) и монтажный клей для витков — декоративные элементы без жёсткой
  геометрии; канат смоделирован как part без 'at' + joint type hang к столбику (по правилам скилла), клей
  вообще не входит ни в одну категорию фурнитуры/отделки движка и не смоделирован (артикула 794456 нет в
  каталоге Петровича).
- Обтяжка основания ковролином — опциональная отделка «по желанию» без деталей в тексте, не моделируется.
